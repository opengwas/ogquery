`ogquery.digests` poses a reference release's questions of another release and projects the answers onto the reference's index space (opengwas/ogquery#13, opengwasdb ADR 0109 §8b). `reference_of(q)` takes a release's question set and its `analysis_id` and ALID index maps as a `Reference`; `release_answers(path, reference=...)` and `release_digests(path, reference=...)` ask them, drop every row the reference has no index for **before** any limit (`top_hits/limit` is posed without one and limited after the projection), and refuse an Analysis the release does not hold (`refusals/unheld/<analysis_id>`) rather than answer it empty. A spliced release and its source then answer comparably, though every `variant_index` and `analysis_index` differs. Without `reference`, nothing changes.
