`ogquery.digests` poses a reference release's questions of another release and projects the answers onto the reference's index space (opengwas/ogquery#13, opengwasdb ADR 0109 §8b). `reference_of(q)` takes a release's question set and its `analysis_id` and ALID index maps as a `Reference`; `release_answers(path, reference=...)` and `release_digests(path, reference=...)` ask them, drop every row the reference has no index for **before** any limit (`top_hits/limit` is posed without one and limited after the projection, in the canonical `(variant_index, analysis_index)` order, which is not the facade's analysis-major order), and refuse **every** Analysis of the reference the release does not hold, sampled or not (`refusals/unheld/<analysis_id>`), rather than answer it empty. A projected record is stamped with the reference's index spaces. `projected_arrays(path, reference)` returns the decoded, projected answers themselves, and `array_differences(a, b, eaf_tolerance=...)` compares them exactly, `eaf` within a tolerance, so a splice proof compares numbers before hashing. Without `reference`, nothing changes.
